# SocialConnect Frontend

React + TypeScript + Vite + Axios, atividade da aula 09.

```bash
npm ci
npm run dev
```

Acesse http://localhost:5173 com a API em execução na porta 8080.
`npm run build` verifica TypeScript e gera o build em `dist/`.
As instruções completas da entrega estão em `../README.md`.
